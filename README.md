# Tida — AI Conversational Assistant

Tida is a Flutter-based AI conversational application designed for real-time text and voice interaction.

## Overview

Tida combines a Flutter client with a Python backend to provide real-time AI communication, voice interaction, and conversational features.

## Key Features

* Real-time text conversations
* Real-time voice conversations
* LLM-powered interactions
* Voice synthesis
* Contact integration
* Maps and navigation
* Background execution
* Streaming conversational UI

## Technical Stack

* **Flutter**
* **Dart**
* **BLoC**
* **Clean Architecture**
* **WebSocket**
* **REST API**
* **Python Backend**
* **LLM**
* **Voice Synthesis**

## Architecture

Tida follows **Clean Architecture** principles with **BLoC** for state management and separation of concerns.

The application communicates with a Python backend through REST APIs and WebSockets for real-time text and voice interactions.
